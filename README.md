# Stock_Price_Analysis-
Stock price movement analysis and candlestick visualization using R and quantmod.

 Stock Price Movement Analysis (R)

Analyzes and visualizes stock price movements using historical Open, High, Low, and Close (OHLC) data.

 What it does

-  Reads stock price data from CSV
-  Converts and organizes the Date column
-  Creates an OHLC time-series object using "xts"
-  Generates a candlestick chart using "quantmod"
-  Visualizes daily stock price movements
- 🟢 Highlights upward price movements in green
- 🔴 Highlights downward price movements in red

Sample Output

"Stock Price Movement" (Stock%20Price%20Movement.png)

 How to run

1. Open "Stock Price Movement.R" in RStudio
2. Run the script
3. Select "stock_dataset.csv" when prompted
4. The candlestick chart will be generated

 Insights

-  Shows the opening and closing price movement
-  Identifies upward and downward price movements
-  Helps understand stock price trends over time
-  Candlestick visualization provides a clear view of daily price behavior
